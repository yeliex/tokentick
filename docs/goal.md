# TokenTick 当前执行目标

更新：2026-09-11。以本文和 [需求文档](requirements.md) 解释最新完成条件，历史验收只证明当时版本。

本轮目标已按用户要求创建并执行，范围为 [逐条用量与 tier 价格方案](usage-and-tier-pricing-plan.md)。代码、137 项测试、真实数据、分发和运行验收已完成，证据见 [优化验收](optimization-validation-20260911.md)。七天限额窗口判定沿用已核对方案，本轮增加窗口本地 tokens／金额查询缓存。

在本仓库完成 macOS 26+、仅 Apple Silicon 的 TokenTick：SwiftUI 原生 App 与独立 CLI target 共用 Swift Core，以 SQLite 保存可追溯的本地用量、模型历史价格和统计缓存，提供足够核对真实数据的界面。通过当前 macOS 27 设备的构建运行、真实数据、迁移恢复及分发验证；不要求另外进行 macOS 26 实机验收。

## 当前范围及完成条件

| 事项 | 当前要求 |
| --- | --- |
| 架构与签名 | 仅 arm64，不包含 Intel 兼容实现；App／CLI 统一 ad-hoc 签名和 ZIP 分发，无付费 Developer Program 或公证门槛 |
| 数据归属 | account_id、thread_id 允许为空；全局保留本地未知账号用量，模型 NULL 归“其他”并计入 tokens；projectless 归 Chat（无项目聊天），项目名称优先 Codex 名称再目录名，任务切换项目后历史使用最新归属；按账号查询只计明确匹配；API 日桶只保留内存；可比范围内展示扣除本地已覆盖用量后的未知模型参考差额，不入事实或金额统计 |
| 日志位置 | 每次操作实时读取进程 CODEX_HOME，空值默认 ~/.codex；没有目录设置项。扫描开始后固定本次根目录，监听器重新检测并切换来源 |
| 采集与恢复 | 目录监听优先，兜底扫描；增量游标、归档移动、压缩／解压、fork／revert 去重；已入库事实不随源文件消失而删除 |
| 价格与金额 | 按 model＋date＋tier 保存价格；Fast 独立行，长上下文分项倍率推导缺少的组合价格并留依据；每日同步 models.dev 新 tiers／modes 格式，变化才新增日期记录；最早快照可用于更早历史；内置 JSON 补齐无 API 历史的旧模型；rollout 缺 Fast 时补查额外日志，再按普通模式计价，保留依据；缺模型或费率保持空值 |
| 历史额度 | 只持久化主桶 `codex` 七天观测，按稳定截止归并；分开显示推算起算、恢复观测及窗口最后使用率，空闲零值与截止抖动不新增窗口；窗口 tokens／金额查询本地事实，跨界 turn 按开始时间近似，稳定历史可缓存 |
| 实时额度 | API／日志取得的所有额度类型保留内存和观测时间；完整实时快照不落库、不在重启后从数据库恢复 |
| 统计及界面 | 总览、每日、任务、项目等查询与缓存一致；UI 足够查看和核对数据；token 显示 K／M／B／T，保留精确整数供详情及 CLI JSON 使用 |
| 验证 | 关键测试、历史副本事实一致、缓存与直接查询一致、无自动备份的事务迁移、中断恢复、并发和实际性能记录；当前设备 App 运行与基本数据交互，arm64 App／CLI 分发包验证 |

进程环境以实时 getenv 为准；其他 shell 的 export 不会自动传入已经运行的 App。API 日桶口径、历史账号、模型及 Fast 观测无证据时保持未知；Fast 计价遵循默认普通规则，不将它冒充已观测的模式。

## 目标状态维护

本轮实现与验收已完成：tier 价格、逐条用量及 UTC hour／minute、API 内存参考差额、窗口用量缓存均已落地，默认库已迁移并重扫，新版 App 已运行并连接默认库。代码随本轮提交推送后关闭执行目标。任务级 API 模型持久化及 API 金额计算已取消；不扩大 UI 设计范围。验收证据见 [优化验收](optimization-validation-20260911.md)。

此前范围已通过 [完成审计](completion-audit.md)：数据、构建、分发和本机原生界面验证完成，菜单栏两条操作链由用户人工确认正常。此前任务目标已按该审计关闭。历史缺失字段仍保持未知，后续 UI 细化另行迭代。
