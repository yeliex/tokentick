## 当前范围及完成条件

| 事项 | 当前要求 |
| --- | --- |
| 架构与签名 | 仅 arm64，不包含 Intel 兼容实现；App／CLI 统一 ad-hoc 签名和 ZIP 分发，无付费 Developer Program 或公证门槛 |
| 数据归属 | account_id、thread_id 允许为空；全局保留本地未知账号用量，模型 NULL 归“其他”并计入 tokens；projectless 归 Chat（无项目聊天），项目名称优先 Codex 名称再目录名，任务切换项目后历史使用最新归属；按账号查询只计明确匹配；未归属任务的 API 日用量独立保存，不参与用量汇总，不推算跨设备差额 |
| 日志位置 | 每次操作实时读取进程 CODEX_HOME，空值默认 ~/.codex；没有目录设置项。扫描开始后固定本次根目录，监听器重新检测并切换来源 |
| 采集与恢复 | 目录监听优先，兜底扫描；增量游标、归档移动、压缩／解压、fork／revert 去重；已入库事实不随源文件消失而删除 |
| 价格与金额 | 每日同步 models.dev，价格变化才新增日期记录；最早快照可用于更早历史；内置 JSON 补齐无 API 历史的旧模型；rollout 缺 Fast 时补查额外日志，再按普通模式计价，保留依据；缺模型或费率保持空值 |
| 历史额度 | 只持久化主桶 `codex` 七天观测，按稳定截止归并；分开显示推算起算、恢复观测及窗口最后使用率，空闲零值与截止抖动不新增窗口 |
| 实时额度 | API／日志取得的所有额度类型保留内存和观测时间；完整实时快照不落库、不在重启后从数据库恢复 |
| 统计及界面 | 总览、每日、任务、项目等查询与缓存一致；UI 足够查看和核对数据；token 显示 K／M／B／T，保留精确整数供详情及 CLI JSON 使用 |
| 验证 | 关键测试、历史副本事实一致、缓存与直接查询一致、无自动备份的事务迁移、中断恢复、并发和实际性能记录；当前设备 App 运行与基本数据交互，arm64 App／CLI 分发包验证 |

进程环境以实时 getenv 为准；其他 shell 的 export 不会自动传入已经运行的 App。API 日桶口径、历史账号、模型及 Fast 观测无证据时保持未知；Fast 计价遵循默认普通规则，不将它冒充已观测的模式。
