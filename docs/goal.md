# TokenTick 当前执行目标

更新：2026-09-10。按用户后续更正维护，以本文和 [需求文档](requirements.md) 解释本任务的完成范围；旧执行日志中的待办不自动成为当前验收门槛。逐项验证见 [验收状态](acceptance-status.md)。

在本仓库完成 macOS 26+、仅 Apple Silicon 的 TokenTick：SwiftUI 原生 App 与独立 CLI target 共用 Swift Core，以 SQLite 保存可追溯的本地用量、模型历史价格和统计缓存，提供足够核对真实数据的界面。通过当前 macOS 27 设备的构建运行、真实数据、迁移恢复及分发验证；不要求另外进行 macOS 26 实机验收。

## 当前范围及完成条件

| 事项 | 当前要求 |
| --- | --- |
| 架构与签名 | 仅 arm64，不包含 Intel 兼容实现；App／CLI 统一 ad-hoc 签名和 ZIP 分发，无付费 Developer Program 或公证门槛 |
| 数据归属 | account_id、thread_id 允许为空；全局保留本地未知账号用量，按账号查询只计明确匹配；未归属任务的 API 日用量独立保存，不参与用量汇总，不推算跨设备差额 |
| 日志位置 | 每次操作实时读取进程 CODEX_HOME，空值默认 ~/.codex；没有目录设置项。扫描开始后固定本次根目录，监听器重新检测并切换来源 |
| 采集与恢复 | 目录监听优先，兜底扫描；增量游标、归档移动、压缩／解压、fork／revert 去重；已入库事实不随源文件消失而删除 |
| 价格与金额 | 每日同步 models.dev，价格变化才新增日期记录；最早快照可用于更早历史；按有证据的普通／Fast／长上下文组合计算请求分项金额，缺失保持空值 |
| 历史额度 | 只持久化周额度观测，结合日志及后续 API 识别自然／疑似手动重置；显示重置前最后观测百分比，不冒充最终百分比，不将截止时间漂移当重置 |
| 实时额度 | API／日志取得的所有额度类型保留内存和观测时间；完整实时快照不落库、不在重启后从数据库恢复 |
| 统计及界面 | 总览、每日、任务、项目等查询与缓存一致；UI 足够查看和核对数据；token 显示 K／M／B／T，保留精确整数供详情及 CLI JSON 使用 |
| 验证 | 关键测试、历史副本事实一致、缓存与直接查询一致、数据库备份迁移、中断恢复、并发和实际性能记录；当前设备 App 运行与基本数据交互，arm64 App／CLI 分发包验证 |

进程环境以实时 getenv 为准；其他 shell 的 export 不会自动传入已经运行的 App。API 日桶口径、历史账号、模型或 Fast 状态无证据时保持未知，不以补猜数据作为完成条件。
