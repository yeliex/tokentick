# Turn 用量重建验证

日期：2026-09-10。范围：fork 去重、新旧格式重复、turn 汇总结构及未上线数据库重建。历史额度重置未修改。

## 实现与数据切换

- `turn_usage` 保存唯一 turn 和最早原始任务；`usage` 保存模型／日期／Fast／长上下文汇总分项。请求 ID 仅进入采集去重状态，不再有请求级业务行。
- 不查询祖先链。fork 的完整或部分同 turn 副本不累加；原始任务继续追加同 turn 时正常增长；更早原始来源晚到会替换副本归属及分项。
- 两条用量流累计基线独立，新格式及其对应旧格式别名只累计一次。长上下文按单次调用输入判断，聚合 token 不作为单次上下文。
- 按用户授权，v6 直接清空旧用量、扫描游标、统计缓存及维护断点后重扫；没有旧数据修复或自动备份，没有改写原始 Codex 日志。价格、任务缓存及 API／周额度独立数据保留。

## 本机全量结果

扫描 1,541 份文件，共 9,240,272,795 字节，耗时 218.924 秒；无采集错误。接受 119,568 条用量事件，过滤 63,995 条重复事件及 13,413 条已有继承边界事件。得到 10,220 条主记录、10,241 条统计分项；主记录包含无法取得 turnId 的来源任务桶，不能全部称为已知 turn。

## 边界

汇总分项已丢弃逐响应时间分布。切换到其他时区后，若分项首尾跨新日期，则归日期未知；长上下文阈值改变且分项需要重新拆分时金额留空、报告需重扫。要恢复精确新分布，需清空用量及游标后在目标规则下重采；不能承诺源日志消失后还原任意新粒度。此限制不影响采集时既定统计时区和价格档位的汇总。

历史周额度重置仍按原实现，已知误判尚未修复。跨设备 API 差额及任务级金额补充仍按原缺口维护，本次不宣称原始全部需求完成。
