日期：2026-09-10。范围：主额度桶 `codex` 的 10,080 分钟周窗口；本机 macOS 27 Apple Silicon。实现规则见 [方案](weekly-reset-plan.md)，数据结构见 [需求](requirements.md)。

## 结论

历史计算已替换任务内相邻观测差值算法。原先被误认的 3,073 条自然重置不再沿用；未知账号按截止窗口归并证据，不冒认账号或重置。Spark 等附加额度桶不进入历史统计，实时额度继续展示所有类型。

2026-09-10 本地重建快照共 70 条历史结果：68 条未知账号窗口证据、1 次疑似提前重置、1 次边界变化。未知账号窗口可能包含不同账号的同截止证据，不能按窗口数宣称真实账号周期数。历史缓存不包含尚未结束且没有变化事件的当前窗口。

主桶证据排除计数：继承 2,277 条，其他任务拥有的 fork turn 副本 12,782 条，fork 创建时刻回放 60 条，过期 5 条。共 15,124 条；排除原因互斥，原始观测仍留存。既有附加桶观测保留但不读取，新采集仅保存主桶周额度。

## 性能及边界

真实库主桶约 13.36 万条观测。一次包含缓存重建的 Debug CLI 查询耗时 5.91 秒，随后缓存查询 26 毫秒（进程级计时）。这是当前快照测量，不是持续性能保证。当前按需重建整个主桶周期缓存，观测或 turn 归属更新会失效；尚未实现局部时间线增量重建。App 在后台任务中查询，主线程不执行扫描。

最后值、峰值与最终用量分开；没有终态证据时最终百分比保持未知。周期 token／金额缺少账号及额度桶路由证据，仍为空，不能靠百分比或时间范围猜测。跨设备 API 补量及计价仍是独立未完成需求，本次不宣称整个项目完成。

本地证据：`.build/audit/weekly-cycles/` 中的 `before.json`、`sync.json`、`history-main.json`、`timing-main.json`；测试与构建日志位于 `.build/logs/weekly-*.log`。日志持续变化，数量以本次快照为准。
