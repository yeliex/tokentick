## 时间含义

- **窗口起算（推算）**：稳定截止减七天，表示新额度开始固定计时的候选时刻，不是手动点击重置的时刻。
- **首次观测**：日志／已保存 API 首次看到对应新窗口的时间，可能晚于第一条消息。
- 重置后空闲期间 0% 的滚动截止不形成多个窗口；待出现正用量、截止稳定后，归并早期对应观测。
- **该窗口最后已观测用量**仅属于该行窗口，不是上一行窗口的结束值；尚未确认账号和结束边界时，不能称为重置时精确最终用量。
