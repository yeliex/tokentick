# TokenTick 当前验收状态

更新：2026-09-10。按用户最新需求调整范围，以 [需求文档](requirements.md) 和 [执行目标](goal.md) 为准。当前范围验收通过，逐项完成证据见 [完成审计](completion-audit.md)。

| 当前要求 | 实现与验证 |
| --- | --- |
| macOS 26+，仅 Apple Silicon | Xcode 固定 arm64，打包脚本只接受 arm64；App 与 CLI Debug 构建通过。当前 macOS 27 宿主构建运行通过；用户确认无需另做 macOS 26 实机验收 |
| 全局及账号统计 | 全局保留未知账号本地用量；账号筛选只计明确归属；未归属任务 API 记录不参与汇总。直接查询及缓存测试通过 |
| 动态 CODEX_HOME | 每次操作实时 getenv，空值回退 ~/.codex；移除设置项与 CLI 参数，环境变更测试通过。扫描内部固定本次根目录 |
| 监听优先 | FSEvents 事件合并，正常监听 30 分钟兜底，监听失败 1 分钟，远端独立 5 分钟；通知、节流、取消及恢复测试通过 |
| 首份价格覆盖历史 | 最早快照前的请求使用该快照，后续继续按日期匹配；历史重算、中断恢复及事实不变测试通过 |
| 历史周额度 | 仅持久化 10080 分钟窗口；日志回填与 API 观测，支持自然／疑似手动重置，未知边界单独标记。记录重置前最后观测，不能保证最终百分比；真实数据已排除仅截止时间漂移的伪重置候选 |
| 当前额度 | 全部可获取桶／窗口和原始附加类型保留内存，不从数据库恢复实时快照；API 优先、无 API 时日志补充 |
| 数据迁移 | v5 备份后迁移周额度、删除五小时历史、允许日桶账号为空、使缓存失效；迁移及备份内容测试通过 |
| token 单位 | 全部界面采用 K／M／B／T，最多两位小数并可悬停查看精确整数；0、999、1K、1M 边界、M／B／T 与未知值验证通过；数据库及 CLI JSON 保留整数 |
| 本地签名 | 保持 App／CLI ad-hoc 分发，不需要付费 Developer Program 或 Apple 公证 |

本轮 `swift test`：110 个测试、19 个测试套件通过。日志位于本机忽略目录 `.build/logs/current-tests.log`；App 和 CLI 构建分别见 `current-app-build.log`、`current-cli-build.log`。显示格式验证位于 `.build/audit/token-format-check.swift`。

现阶段 UI 只需足够查看及核对真实数据；精细样式、完整键盘／VoiceOver、Intel 及付费签名不作为本轮完成门槛。既有本机扫描、恢复和性能验证见 [实现计划](implementation-plan.md)、[维护恢复](maintenance-recovery.md) 与 [历史 Release 验证记录](release-validation.md)，其中旧范围仅供追溯。

限制：未取得的账号、模型、模式、价格及请求到额度桶的归属仍保持未知；没有周额度重置前后观测时，不伪造周期或最终用量。API 日桶与本地记录口径未证明可比，保持独立数据，当前范围不要求猜测跨设备差额。真实历史副本已完成全量重扫、重算、五维直接／缓存对比和 Release CLI 验证，见 [2026-09-10 验证](validation-20260910.md)。默认 App 已重启到新版，实际数据库已完成 v5 迁移、历史重算和缓存更新，后续本地同步无问题。当前设备原生界面已验证总览 M／B 单位及额度页：3 个实时窗口、历史仅周额度。原生应用菜单的设置入口已验证，界面只有环境变量说明和自动同步开关，显示实际库容量及 2 份迁移备份。菜单栏打开设置、关闭主窗口后恢复窗口两项由用户实际操作确认正常。
