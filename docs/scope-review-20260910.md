修复后 `./script/build_and_run.sh --verify` 成功，运行中的 App 已更新。此前菜单栏设置和关闭主窗口后恢复窗口两项由用户确认通过，本次不重复冒充自动化验收。先前默认价格和项目映射文档中的“锁屏未验收”描述为历史状态，由本次结果补齐。

## 未完成的 API 补齐

实验性协议的 `threadUsage.groups` 支持可空模型、speed、输入／缓存／净新增输入／输出／总 tokens，任务层支持可空 USD 估值。只要模型、token 分项和适用价格规则足够明确，就能自行换算金额，不需要服务端直接提供金额。模型调用次数和单一总 tokens 不足以精确计价。

本次对当前任务和 4 个远端任务实际请求，5 次 RPC 均成功，前后账号一致，但 `threadUsage` 全部为 NULL；账号查询得到 196 个日桶。当前客户端尚未接入任务级读取、模型分组持久化、API token 计价及与本地去重对账。需分别记录“实现缺口”和“当前无可用服务端数据”，不能合并成“接口不支持金额”。

后续需用有效响应确认输入是否包含缓存、speed 含义和覆盖范围；跨日期累计分组缺少逐请求日期与上下文长度，不能假装精确应用历史价和长上下文档位。API 与本地统一账号、时间和 token 口径后仅补差额，无法绑定任务的部分归“其他”；服务端 USD 估值与本地公开价格估值区分来源。不得把已入库的 634.73M remote tokens 再次完整加入。
