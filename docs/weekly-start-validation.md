## 数据库和性能

v9 迁移成功，`quick_check` 为 `ok`。只清空并重建派生窗口缓存，没有备份、清空或重算原始 token／金额。此前核对的 AIChat 任务仍为 **43,009,157 tokens**。

在本机默认库的一次 Debug CLI 测量中，首次查询 0.655 秒，紧接缓存查询 0.025 秒；未知账号首次查询 0.795 秒，指定账号首次查询 0.121 秒。均包含 CLI 进程开销，不能视为稳定性能保证。SQLite 汇总数值证据后仅向 Swift 返回截止统计点；全局、未知及指定账号结果分别缓存。

## 边界

秒级归并采用核对清单中的固定锚点 60 秒规则，附近零值采用 30 秒范围。极短时间内多次真实重置或超出该范围的上游时钟偏差尚无已验证样本；不将阈值描述为上游协议保证。单独零值没有正用量支持时不生成窗口，当前实时面板仍可显示零值。

最后观测不保证就是恢复额度时的精确最终值；未知账号不自动绑定，归零观测也不确认手动操作。周期 tokens／金额仍缺路由与账号证据。

本地验收产物位于 `.build/audit/weekly-start-validation/`：`month.json`、`timing.json`、`unknown.json`、`account.json`、`extra.json`、`checks.json`。日志为 `.build/logs/weekly-start-*.log` 与 `.build/logs/app-build.log`。
